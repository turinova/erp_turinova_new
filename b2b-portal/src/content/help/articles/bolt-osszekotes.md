# Bolt összekötése (Shoprenter API)

A ProGate a Shoprenter API-n olvassa a termékeket és írja a partnerárat. Kell hozzá egy API felhasználó.

## Hol a kulcs?

Shoprenter admin: Beállítások, majd API.

Ott van a név és a jelszó. Másold ki mindkettőt.

## Mit írj be nálunk?

Portál: Beállítások.

1. Shoprenter név: az API felhasználó neve
2. Shoprenter jelszó: az API jelszava
3. Bolt címe: a webshop URL-je (https://…)

Nyomd meg: **Összekötés és betöltés**.

Ez egy lépés: ellenőrzi a kulcsot, majd elindítja a termékek, csoportok és rendelések másolását. Nem kell külön frissítő gomb.

## Mi történik utána?

Az Áttekintésen látod a lépéseket (bolt, termékek, csoportok, rendelések). Pár perc alatt kész.

Bolt API Hiba: nézd a jelszót. Sokszor elgépelés, régi jelszó, vagy szóköz a végén.

A Gomb chip mutatja, látszik-e a gyors rendelés a boltban. Ezt a Widget oldalon kapcsolod.

Ha később újra kellene a terméklista: Beállítások → Haladó → Termékek újratöltése.
